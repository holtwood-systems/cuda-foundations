# Measured benchmark: RTX 4090, 2026-11-06

Second repository-measured page (after `rtx3060-laptop-2026-08-17.md`),
this time with raw Google Benchmark JSON archived under
`data/2026-11-06-rtx4090/`.

## Environment

| Item | Value |
| --- | --- |
| GPU | NVIDIA GeForce RTX 4090, 49140 MiB, sm_89 |
| Driver | 550.107.02 (CUDA 12.4 UMD) |
| CUDA toolkit | 12.8.61 (nvcc) |
| Host | Linux 5.15, GCC 11.4 |
| Build | CMake `release` preset, `-DCMAKE_CUDA_ARCHITECTURES=89`, `-DTC_BUILD_PYTHON=OFF` |
| Commit | see `git log` of this commit |

Build note: `TC_BUILD_PYTHON=ON` (default) fails on this host because the
pybind11 module compiles `include/tensorcraft/kernels/attention.hpp`
(CUDA kernel code) with the host C++ compiler — `blockIdx`/`threadIdx`
undefined. Pre-existing defect, unrelated to the architecture flag;
benchmarks and tests build with the Python module disabled.

## 02-tensorcraft-core benchmarks

Command:

```bash
cmake --preset release -DCMAKE_CUDA_ARCHITECTURES=89 -DTC_BUILD_PYTHON=OFF
cmake --build build/release -j16
./benchmarks/gemm_benchmark --benchmark_format=json --benchmark_min_time=0.3s
./benchmarks/attention_benchmark --benchmark_format=json --benchmark_min_time=0.3s
./benchmarks/conv_benchmark --benchmark_format=json --benchmark_min_time=0.3s
```

### GEMM ladder (GFLOPS, real_time)

| Kernel | 256³ | 512³ | 1024³ | 2048³ |
| --- | --- | --- | --- | --- |
| Naive | 1889 | 4838 | 5288 | 5371 |
| Tiled | 2211 | 5734 | 6616 | 6757 |
| DoubleBuffer | 2246 | 6058 | 6842 | **6983** |

Optimization ladder gain at 2048³: Naive→DoubleBuffer **+30%**; Tiled
contributes most of it (+26%), double buffering adds ~3%.

## Boundaries

- Single GPU, single run; Google Benchmark steady-state iterations but no
  cross-run variance statistics.
- Teaching-grade kernels: numbers characterize the ladder on this GPU, not
  cuBLAS/cuDNN-level performance.
- No profiler counters (`ncu` blocked by `ERR_NVGPUCTRPERM` on this host).
- Not comparable with the RTX 3060 page as a before/after: different GPU,
  toolkit (12.0 vs 12.8) and compiler.
